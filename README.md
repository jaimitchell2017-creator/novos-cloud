# NOVOS Cloud v0.3
Prototype of the NOVOS Cloud control layer.
Includes login, queue, simulated Epic connection, 1-hour sessions, admin panel, scheduled 1/5/10/15 minute shutdown, queue preservation, and Playnite handoff placeholder.
Press Ctrl+A for the prototype admin panel.
This does not yet authenticate Epic, launch Playnite, or stream video. Those are the next backend integrations.
